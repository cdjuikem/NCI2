# NLP-Keyword-Intelligence-Analysis 🔍
### Collaborative Project: Data Mining, Keyword Extraction & Semantic Classification

## 📌 Project Overview
This collaborative research project focuses on **Natural Language Processing (NLP)** and **Data Analytics**. Our team developed a pipeline to crawl, extract, and classify keywords and queries to understand search intent and semantic relationships.

## 👥 Contributors
- **Dr. Clotilde Djuikem** (@cdjuikem): Data modeling, Python/Excel integration pipelines.
- **Team Collaborators:** @s-leem, @GhHiva, @Irushi12.

## 🛠 Key Features & Contributions
- **Data Scrapping & Mining:** Extraction of technical queries and links from web sources.
- **Keyword Classification:** Automated categorization of datasets using Python (Pandas/Jupyter).
- **Semantic Analysis:** Identifying relationships between "collected verbs" and "search queries".
- **Data Engineering:** Pre-processing of `.xlsx` datasets for analysis.

## 💻 Tech Stack
- **Languages:** Python (Jupyter Notebooks)
- **Libraries:** Pandas, NumPy, Regular Expressions.
